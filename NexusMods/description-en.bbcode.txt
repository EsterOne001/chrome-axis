Chrome Axis adds analog steering, throttle and brake to [b]Cyberpunk 2077 on Windows[/b]. Connect your wheel and pedals through a wheelbase or select a separate DirectInput device for each axis. The included [b]Chrome Axis[/b] app lets you calibrate your setup, see live input, set dead zones and save named profiles. You can keep the game's own controls for any axis.

This prototype targets [b]Cyberpunk 2077 2.5[/b]. Hardware behavior depends on the axes and buttons your Windows drivers expose.

[size=4][b]What you can do[/b][/size]

• Calibrate a wheel and two pedals, including pedals that share an axis. If your driver offers separate pedal axes, select them to measure both pedals simultaneously.
• Save different setups as profiles. Each keeps its axis calibration, accessory bindings and force-feedback settings.
• Bind wheel buttons, D-pad directions, paddles, a shifter, a handbrake or an accessory axis to keyboard keys.
• Enable optional DirectInput force feedback on a compatible steering axis. Steering resistance varies with the vehicle, and collision jolts can be turned off separately.
• Try progressive steering, throttle and braking with the keyboard in [b]Simulation[/b], even without a wheel, pedals or a saved profile.

[size=4][b]Requirements and compatibility[/b][/size]

• [b]Windows x64 and Cyberpunk 2077 patch 2.5[/b], with [font=Courier New]Cyberpunk2077.exe[/font] file version [b]3.0.88.46235[/b]. The plugin checks this version when it loads.
• [b]RED4ext 1.31.1[/b]. [url=https://www.nexusmods.com/cyberpunk2077/mods/2380]Nexus Mods[/url] · [url=https://github.com/wopss/RED4ext/releases/tag/v1.31.1]GitHub release 1.31.1[/url]
• [b]redscript[/b], with [b]0.5.32[/b] as the reference version for this release. [url=https://www.nexusmods.com/cyberpunk2077/mods/1511]Nexus Mods[/url] · [url=https://github.com/jac3km4/redscript/releases/tag/v0.5.32]GitHub release 0.5.32[/url]
• For physical controls, use a device whose driver exposes the axes or buttons through [b]DirectInput[/b]. Check them in Windows Game Controllers ([font=Courier New]joy.cpl[/font]). Force feedback also requires a DirectInput actuator on the calibrated steering axis.

[size=4][b]Install and set up a wheel[/b][/size]

1. Close the game and install the requirements. In Vortex, import the Chrome Axis ZIP using [b]Install From File[/b], then enable and deploy it. For a manual install, extract the ZIP into the game folder so that [font=Courier New]archive[/font] and [font=Courier New]red4ext[/font] sit alongside [font=Courier New]bin[/font].
2. Open [font=Courier New]red4ext/plugins/chrome_axis/ChromeAxis.exe[/font] from the [b]game folder[/b]. The app is in French. In [b]Matériel USB[/b], click [b]Actualiser[/b] and select a device for [b]Volant[/b] (wheel), [b]Accélérateur[/b] (throttle) and [b]Frein[/b] (brake). Select [b]Commandes du jeu[/b] to keep the game's controls for an axis.
3. Click [b]Calibrer les axes[/b]. Capture the wheel at its centre and both limits, then each pedal at rest and fully pressed. Check the live values and adjust [b]Zone morte (%)[/b] if a control moves at rest. Click [b]Enregistrer le profil[/b] to save your setup. Use [b]Sélectionner un profil…[/b] to switch to or create a named profile.
4. Click [b]Activer l’USB en jeu[/b]. USB input starts disabled. Once you've saved and enabled it, you can close the app. Sit in the driver's seat with the game in the foreground, centre the wheel and release the pedals and accessories to arm them. The HUD shows [b]USB PRÊT[/b] when your configured controls are armed and briefly shows [b]SIGNAL USB[/b] when the mod applies input.

For force feedback, save the steering axis first, then open [b]Retour de force…[/b] and enable it for the current profile. Start at low intensity. The setting ranges from [b]1% to 35%[/b] of nominal DirectInput force. The panel checks whether the driver exposes the required actuator and offers an invert option if the wheel pulls away from centre.

To return to the game's regular controls, open the app and select [b]Désactiver l’USB en jeu[/b].

[size=4][b]Try it without hardware[/b][/size]

Open [b]Simulation[/b], then click [b]Activer dans le jeu[/b] and [b]leave Chrome Axis running[/b]. In the game, sit in the driver's seat and release the simulation keys once before testing. Hold [b]Numpad 4 / 6[/b] to steer left or right, [b]Numpad 8[/b] to accelerate and [b]Numpad 2[/b] to brake, with Num Lock on. [b]F6 / F7 / F8 / F10[/b] are the alternatives in the same order. The HUD displays [b]SIMULATION[/b] when the game receives the app's signal. To finish, click [b]Arrêter la simulation[/b] or close the app.

[size=4][b]Paddles, shifters and accessories[/b][/size]

Open [b]Matériel USB → Accessoires…[/b], then choose the wheelbase or standalone USB device that exposes the input. In [b]Boîte / palettes…[/b], capture the up/down positions for a sequential shifter, or individual positions on a 6-, 7- or 8-speed H-pattern shifter, including reverse. Assign the keys, click [b]Appliquer[/b] in the wizard, then [b]Enregistrer[/b] in the accessory panel. USB input must be enabled for bindings to work in the game.

Chrome Axis maps accessory inputs to keys. For manual shifting, set the same keys in a separate transmission mod. An H-pattern shifter needs a transmission mod that accepts a separate key for each gear. For sequential shifting, [b]Numpad + / −[/b] are suggested bindings to try with Manual Transmission V10 4.3. That combination still needs an in-game test. [url=https://www.nexusmods.com/cyberpunk2077/mods/28342]Manual Transmission V10[/url]

[size=4][b]Troubleshooting and updates[/b][/size]

• [b]The HUD stays on USB EN ATTENTE.[/b] Keep the game in the foreground, centre the wheel, release the pedals and check that each configured input responds in [font=Courier New]joy.cpl[/font]. For a device that no longer exposes the saved axis, check its driver settings and recalibrate.
• [b]The gauges move in the app but the car does not respond.[/b] Check the newest [font=Courier New]red4ext/logs/chromeaxis-*.log[/font]. [font=Courier New]Chrome Axis USB configuration directory[/font] shows which profile folder the plugin reads. Compare it with [b]Dossier des profils[/b] in the app. [font=Courier New]USB axes[/font] reports the state of each axis. If the mod log is missing, check [font=Courier New]red4ext-*.log[/font] for plugin loading or script compilation errors.
• [b]Windows reports a missing [font=Courier New]MSVCP140.dll[/font] or [font=Courier New]VCRUNTIME140.dll[/font].[/b] Install the Microsoft Visual C++ v14 x64 Redistributable. [url=https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170#latest-supported-redistributable-version]Microsoft download[/url]
• [b]Updating or uninstalling.[/b] Close the game and app, and back up the entire [font=Courier New]red4ext/plugins/chrome_axis/Profil[/font] folder. For an update, disable and deploy the removal of the old release in Vortex, deploy the new release, restore [font=Courier New]Profil[/font], then click [b]Recharger[/b]. To uninstall, remove the mod in Vortex and deploy the change. For a manual install, remove the Chrome Axis plugin folder and [font=Courier New]archive/pc/mod/chrome_axis_hud.archive[/font].

When reporting a bug, include your wheel and pedal models, how they're connected, your game and framework versions, steps to reproduce and the latest relevant log excerpt.
